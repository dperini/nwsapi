An offline-trained decision tree chooses between two exact type-union execution paths. The model predicts cost. The selector engine still determines every match.

Decision: retain existing runtime rule.
Methodology and promotion gate

48 training cases and 48 held-out cases per host. Family assignments precede measurement. At most three tree levels, cost-sensitive splitting, no runtime training or model download. Seven rounds rotate variant order. Native timings are round means; jsdom timings are Mitata round medians. Model evaluation is a separate run using the generated branches.

Promotion requires ≥1.05× geometric mean speedup in each host and ≤1.15× time for every held-out case. Synthetic warm all-results queries support only this experiment. Cold start, mutation, callback, XML, first-result, and real-application validation remain required before a production change.

Ordered element identity is checked before and after timing. The source runtime is unchanged. No GPU or competitor speedup is claimed.
