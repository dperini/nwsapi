# 💖 Thank You!

**nwsapi** is a fast, dependency-free CSS Selectors API engine maintained with passion for the Open Source community. 

As a core underlying engine for many popular tools in the ecosystem (like `jsdom`), millions of projects rely on it every month. A huge thank you goes to everyone who supports its development—whether by contributing code, reporting issues, or sponsoring the project!
