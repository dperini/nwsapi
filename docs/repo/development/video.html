A clearer path to your next change.

Set up, open docs and edit, then review in 48 seconds. Silent, with on-screen captions and illustrated interface scenes.

Follow the guided menu

Run pnpm run dev. Use 1–4 or the arrow keys to preview setup, documentation, review, or setup help. Read the description, then press Enter to run the displayed command.

You can also type the individual commands shown in the video:

Open a terminal in the repository folder. Type a command and press Enter.

  1. Prepare the checkout.pnpm go

    Installs tools and dependencies, then builds the project. Wait for “Setup complete.”

  2. Open the docs and make your change.pnpm run guide

    Opens documentation in your browser. Find the relevant section, then edit your source or documentation. Use another terminal for the next step while the docs server runs.

  3. Review after editing.pnpm run review

    Runs lint, formatting, types, and unit tests in order. Fix the first reported issue and rerun. Finish with git diff.

Setup help: missing tool or wrong version?

Type pnpm run setup:check and press Enter.

This reports Node.js and package-manager versions, whether the pinned checkout tools are ready, and the next command. It does not install or change tools.

For paths, version requirements, and wrapper information, use pnpm run setup:check --details. The older doctor:tools name still works.
